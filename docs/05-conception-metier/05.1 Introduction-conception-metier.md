# Introduction à la conception métier

## Objectif du document

Ce document introduit la conception métier de la marketplace.

Après avoir identifié les acteurs, leurs permissions et leurs cas d'utilisation, cette étape consiste à définir les objets métiers manipulés par la plateforme ainsi que leurs relations et les règles qui régissent leur fonctionnement.

La conception métier constitue le lien entre les besoins fonctionnels et la future conception technique.

---

# Définition de la conception métier

La conception métier décrit le fonctionnement de la marketplace d'un point de vue fonctionnel.

Elle répond notamment aux questions suivantes :

- Quels sont les objets manipulés par la plateforme ?
- Quel est le rôle de chaque objet ?
- Comment ces objets interagissent-ils ?
- Quelles règles doivent être respectées ?
- Comment évoluent les différents processus au cours de leur cycle de vie ?

La conception métier est indépendante des technologies utilisées pour développer l'application.

---

# Périmètre de la conception métier

La conception métier décrit les concepts fonctionnels de la marketplace.

Elle comprend notamment :

- les entités métier ;
- les relations entre les entités ;
- les règles de gestion ;
- les principaux processus métier ;
- les cycles de vie des objets importants.

Elle ne traite pas encore des aspects techniques du projet.

# Objectifs de la conception métier

La conception métier poursuit plusieurs objectifs.

Elle permet de :

- disposer d'un vocabulaire commun pour l'ensemble du projet ;
- définir précisément les objets manipulés par la plateforme ;
- formaliser les règles métier ;
- préparer la modélisation des données ;
- faciliter la conception de l'architecture technique ;
- limiter les ambiguïtés avant le développement.

---

# Principes retenus pour la marketplace

La conception métier repose sur les décisions fonctionnelles validées précédemment.

Les principes suivants sont retenus :

- la plateforme est une marketplace multi-vendeurs ;
- un compte utilisateur peut posséder plusieurs rôles ;
- chaque rôle dispose de permissions spécifiques ;
- les interactions entre les acteurs suivent les cas d'utilisation validés ;
- les règles métier sont centralisées et appliquées de manière cohérente sur l'ensemble de la plateforme.

# Méthodologie

La conception métier sera réalisée selon l'ordre suivant :

1. Identifier les entités métier.
2. Définir leurs responsabilités.
3. Décrire les relations entre les entités.
4. Formaliser les règles de gestion.
5. Décrire les principaux processus métier.
6. Représenter le domaine au moyen de diagrammes UML.

Chaque étape sera validée avant de passer à la suivante.

---

# Résultat attendu

À la fin de cette étape, la marketplace disposera :

- d'un modèle métier cohérent ;
- d'un ensemble de règles de gestion clairement définies ;
- d'une vision globale des interactions entre les principaux objets du domaine.

Cette conception servira de base à la modélisation de la base de données et à la conception de l'architecture logicielle.
