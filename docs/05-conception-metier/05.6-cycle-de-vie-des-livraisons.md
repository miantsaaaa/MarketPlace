# Cycle de vie des livraisons

## Objectif du document

Ce document décrit le cycle de vie métier d'une livraison au sein de la marketplace.

Il présente les différentes étapes traversées par une livraison depuis sa création après la préparation d'une commande jusqu'à sa finalisation.

Le cycle de vie des livraisons constitue une référence pour :

- les processus métier ;
- les règles de gestion ;
- la conception du modèle de domaine ;
- la conception de la base de données ;
- l'implémentation des services métier.

---

# Définition du cycle de vie

Le cycle de vie d'une livraison représente les différents états qu'une livraison peut traverser pendant son traitement.

Chaque changement d'état correspond à une action réalisée par un acteur ou automatiquement par le système.

---

# Principe général

Une livraison est créée lorsqu'une commande globale est prête à être remise au processus de livraison.

Une commande possède une seule livraison associée, même si elle contient des produits provenant de plusieurs boutiques.

La préparation des produits peut impliquer plusieurs vendeurs, mais l'acheteur reçoit une livraison unique correspondant à l'ensemble de sa commande.

La livraison permet de suivre :

- l'acheminement de la commande complète ;
- l'affectation du livreur ;
- l'état d'avancement ;
- la confirmation de réception par l'acheteur.

---

# Acteurs concernés

Les acteurs intervenant dans le processus de livraison sont :

| Acteur            | Responsabilité                                                                |
| Vendeur           | Prépare les produits de sa boutique et les remet au processus de livraison    |
| Système           | Crée et met à jour les informations de livraison                              |
| Livreur           | Transporte et livre la commande                                               |
| Acheteur          | Réceptionne la commande                                                       |
| Administrateur    | Intervient en cas de problème ou de litige                                    |

---

# États d'une livraison

Une livraison peut évoluer selon les états suivants.

| État                      | Description                                                                                                           |
| Créée                     | La livraison est générée après préparation de la commande.                                                            |
| En attente d'affectation  | La livraison existe mais aucun livreur n'est encore attribué.                                                         |
| Affectée                  | Un livreur est responsable de la livraison.                                                                           |
| En récupération           | Le livreur récupère la commande regroupée contenant les produits préparés par les différentes boutiques concernées.   |
| En livraison              | Le livreur transporte la commande vers l'acheteur.                                                                    |
| Livrée                    | La commande complète a été remise à l'acheteur.                                                                       |
| Échec                     | La livraison n'a pas pu être réalisée.                                                                                |
| Annulée                   | La livraison est arrêtée selon les règles métier.                                                                     |

---

# Création d'une livraison

Le processus commence lorsque les produits de la commande sont préparés par les vendeurs concernés.

Le système :

- vérifie que la commande existe ;
- vérifie que les produits nécessaires sont prêts ;
- crée une livraison associée à la commande ;
- initialise son état à **Créée**.

Une livraison ne peut pas exister sans commande associée.

---

# Affectation du livreur

Après la création de la livraison :

- le système place la livraison en attente d'affectation ;
- un livreur disposant du rôle nécessaire peut être attribué ;
- la livraison passe à l'état **Affectée**.

Un livreur peut gérer plusieurs livraisons.

Une livraison concerne un seul livreur à un instant donné.

---

# Récupération du colis

La livraison concerne la commande globale.
Les modalités de regroupement des produits provenant de plusieurs boutiques sont gérées par le système logistique.

Pendant cette étape :

- le livreur confirme la prise en charge ;
- le système met à jour l'état de la livraison ;
- la livraison passe à l'état **En récupération**.

Après récupération réussie, la livraison passe à l'état **En livraison**.

---

# Transport et suivi

Lorsque le livreur transporte la commande :

- la livraison est en cours ;
- son état est **En livraison** ;
- les informations de suivi peuvent être mises à jour.

L'acheteur peut consulter l'évolution de la livraison selon les fonctionnalités disponibles.

---

# Confirmation de livraison

Lorsque la commande arrive chez l'acheteur :

- l'acheteur réceptionne l'ensemble des produits ;
- le livreur confirme la livraison ;
- le système met à jour l'état.

La livraison passe à l'état :

**Livrée**

Une livraison terminée permet à la commande associée d'être finalisée.

---

# Gestion des échecs de livraison

Une livraison peut échouer dans certains cas :

- acheteur absent ;
- adresse incorrecte ;
- impossibilité d'accès ;
- refus de réception ;
- problème logistique.

Dans ce cas :

- le motif de l'échec est enregistré ;
- une nouvelle tentative peut être organisée selon les règles métier ;
- l'administrateur peut intervenir si nécessaire.

---

# Annulation d'une livraison

Une livraison peut être annulée uniquement dans les cas autorisés par les règles métier.

Exemples :

- annulation exceptionnelle d'une commande ;
- problème administratif ;
- décision de l'administrateur.

Une livraison annulée ne poursuit plus son traitement.

# Relations avec les autres entités

Une livraison possède les relations suivantes :

| Entité        | Relation                                          |
| Commande      | Une livraison appartient à une commande           |
| Livreur       | Une livraison peut être attribuée à un livreur    |
| Adresse       | Une livraison possède une adresse de destination  |
| Utilisateur   | L'acheteur reçoit la livraison                    |

Cardinalités :

Commande (1) ↔ (1) Livraison

Livreur (1) ↔ (0..*) Livraison

Adresse (1) ↔ (0..*) Livraison
