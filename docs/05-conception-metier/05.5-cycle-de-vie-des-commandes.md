# Cycle de vie des commandes

## Objectif du document

Ce document décrit le cycle de vie métier d'une commande au sein de la marketplace.

Il présente les différents états qu'une commande peut traverser depuis la validation du panier jusqu'à la finalisation du processus de vente.

Le cycle de vie des commandes constitue une référence pour :

- les processus métier ;
- les règles de gestion ;
- la conception du modèle de domaine ;
- la conception de la base de données ;
- l'implémentation des services métier.

---

# Définition du cycle de vie

Le cycle de vie d'une commande représente les différentes étapes parcourues par une commande au cours de son traitement.

Chaque changement d'état correspond à une action réalisée par un utilisateur ou automatiquement par le système.

---

# Principe général

Un acheteur peut ajouter dans son panier des produits provenant de plusieurs boutiques.

Lors de la validation du panier :

- le système vérifie les produits sélectionnés ;
- le montant total à payer est calculé ;
- un paiement unique est effectué par l'acheteur ;
- après confirmation du paiement, le système confirme la commande globale contenant les produits provenant éventuellement de plusieurs boutiques.

Chaque vendeur reçoit uniquement les lignes de commande correspondant aux produits de sa boutique.

Ainsi :

- l'acheteur effectue un seul paiement ;
- l'acheteur possède une seule commande globale ;
- chaque vendeur reçoit uniquement les produits qui concernent sa boutique ;
- la commande possède un cycle de traitement global ;
- la préparation des produits peut être suivie par boutique.
  
---

# États d'une commande

Une commande peut évoluer selon les états suivants.

| État                      | Description                                                           |
| Créée                     | La commande est générée par le système après validation du panier.    |
| En attente de paiement    | Le paiement est en attente de confirmation.                           |
| Payée                     | Le paiement a été validé.                                             |
| En préparation            | Le vendeur prépare les produits.                                      |
| Expédiée                  | Les produits ont été remis au service de livraison.                   |
| En livraison              | Le livreur effectue la livraison.                                     |
| Livrée                    | Les produits ont été remis à l'acheteur.                              |
| Terminée                  | Le processus commercial est terminé.                                  |
| Annulée                   | La commande est annulée avant sa finalisation.                        |

---

# Création d'une commande

Le processus débute lorsque l'acheteur valide son panier.

Le système :

- contrôle la disponibilité des produits ;
- vérifie les quantités en stock ;
- calcule le montant total à payer ;
- prépare le paiement.

Une fois le paiement validé, une commande globale est créée contenant toutes les lignes de commande issues du panier, indépendamment des boutiques concernées.

---

# Paiement

L'acheteur réalise un paiement unique correspondant au montant total de son panier.

Après confirmation du paiement :

- chaque commande passe à l'état **Payée** ;
- chaque vendeur concerné est informé uniquement des lignes de commande correspondant à sa boutique.

---

# Préparation de la commande

Le vendeur prépare les produits de sa boutique.

Cette étape comprend notamment :

- la vérification des produits ;
- la préparation du colis ;
- l'emballage ;
- la remise au livreur.

Lorsque la commande est remise au service de livraison, elle passe à l'état **Expédiée**.

---

# Livraison

Après l'expédition :

- un livreur peut être affecté à la commande ;
- le suivi de livraison est mis à jour ;
- la commande passe à l'état **En livraison**.

Lorsque les produits sont remis à l'acheteur, la commande passe à l'état **Livrée**.

---

# Finalisation

Après confirmation de la livraison :

- la commande passe à l'état **Terminée** ;
- l'acheteur peut publier un avis sur les produits achetés ;
- l'historique de la commande est conservé.

---

# Annulation d'une commande

Une commande peut être annulée conformément aux règles de gestion de la plateforme.

L'annulation peut notamment intervenir :

- avant la validation du paiement ;
- dans des cas exceptionnels autorisés par les règles métier ou par l'administrateur.

Une commande annulée ne poursuit plus son cycle de traitement.
