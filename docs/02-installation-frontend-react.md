# Installation Frontend React

## Objectif

Cette étape consiste à préparer la création de l'interface frontend de la marketplace.

Le frontend sera responsable de l'interface utilisateur, de la navigation, des interactions avec les utilisateurs et de la communication avec le backend.

    # Paramètres du projet

| Champ             | Valeur                         |
| ----------------- | ------------------------------ |
| Technologie       | React                          |
| Outil de création | Vite                           |
| Langage           | TypeScript                     |
| Nom du projet     | marketplace-frontend           |

    # Décisions techniques

## Frontend

Technologie choisie :

* React

Objectif :

* Créer une interface dynamique pour les différents acteurs de la marketplace :

  * Acheteur
  * Vendeur
  * Administrateur
  * Support
  * Livreur
  
## Langage frontend

Langage choisi :

* TypeScript

Raison :

* Améliorer la fiabilité du code.
* Détecter les erreurs plus tôt pendant le développement.
* Faciliter la maintenance d'un projet marketplace évolutif.
* Respecter les pratiques utilisées dans les projets professionnels.
