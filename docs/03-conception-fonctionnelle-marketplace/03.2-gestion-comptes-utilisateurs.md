# Gestion des comptes utilisateurs

## Compte unique avec plusieurs rôles

La plateforme utilise un système de compte utilisateur unique.

Un utilisateur possède :

- ses informations personnelles ;
- ses identifiants de connexion ;
- ses préférences ;
- un ou plusieurs rôles associés.

---

# Gestion des rôles

Un même compte peut posséder plusieurs rôles selon les besoins.

Rôles disponibles :

- Acheteur
- Vendeur
- Livreur
- Support
- Administrateur

---

# Exemple d'utilisation

Un utilisateur peut être :

- Acheteur pour effectuer des achats sur la plateforme.
- Vendeur pour proposer ses propres produits.

Un même compte peut donc utiliser plusieurs espaces fonctionnels selon les rôles qui lui sont associés.

---

# Gestion des permissions

Les fonctionnalités accessibles dépendent des rôles associés au compte.

Chaque rôle possède :

- des actions autorisées ;
- des ressources accessibles ;
- des limites d'utilisation.

Les permissions seront définies précisément dans la documentation des acteurs du système.
